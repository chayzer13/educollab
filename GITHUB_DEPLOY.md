# Инструкция по деплою на GitHub

## Шаг 1: Установка Git

Если Git не установлен, скачайте и установите его:
- Windows: https://git-scm.com/download/win
- После установки перезапустите терминал

## Шаг 2: Настройка Git (первый раз)

```bash
git config --global user.name "Ваше Имя"
git config --global user.email "ваш.email@example.com"
```

## Шаг 3: Инициализация репозитория

```bash
# Инициализация Git репозитория
git init

# Добавление всех файлов (кроме тех, что в .gitignore)
git add .

# Создание первого коммита
git commit -m "Initial commit: EduCollab platform"
```

## Шаг 4: Создание репозитория на GitHub

1. Перейдите на https://github.com
2. Войдите в свой аккаунт (или создайте новый)
3. Нажмите кнопку **"New"** (или **"+"** → **"New repository"**)
4. Заполните:
   - **Repository name**: `educollab` (или другое имя)
   - **Description**: "Платформа для совместной работы над учебными проектами"
   - Выберите **Public** или **Private**
   - **НЕ** добавляйте README, .gitignore или лицензию (они уже есть)
5. Нажмите **"Create repository"**

## Шаг 5: Подключение локального репозитория к GitHub

После создания репозитория GitHub покажет инструкции. Выполните:

```bash
# Добавьте удаленный репозиторий
git remote add origin https://github.com/chayzer13/educollab.git

# Переименуйте ветку в main (если нужно)
git branch -M main

# Отправьте код на GitHub
git push -u origin main
```

### Автоматический деплой (рекомендуется)

Для автоматизации процесса используйте готовый скрипт:

**Windows (PowerShell):**
```powershell
.\deploy-to-github.ps1
```

**Linux/Mac (Bash):**
```bash
bash deploy-to-github.sh
```

Скрипт автоматически:
- Проверит установку Git
- Инициализирует репозиторий (если нужно)
- Добавит remote origin
- Добавит все файлы
- Создаст коммит
- Отправит код на GitHub

Если GitHub запросит авторизацию:
- Используйте **Personal Access Token** вместо пароля
- Создайте токен: GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token
- Выберите права: `repo` (полный доступ к репозиториям)

## Шаг 6: Проверка

Откройте ваш репозиторий на GitHub:
```
https://github.com/YOUR_USERNAME/educollab
```

Все файлы должны быть загружены.

## Дальнейшие обновления

После изменений в коде:

```bash
# Проверить изменения
git status

# Добавить измененные файлы
git add .

# Создать коммит
git commit -m "Описание изменений"

# Отправить на GitHub
git push
```

## Важные замечания

⚠️ **Безопасность:**
- Файлы `.env` автоматически игнорируются (не попадут в репозиторий)
- Загруженные файлы пользователей (`backend/uploads/`) также игнорируются
- **НЕ** коммитьте пароли, токены и другие секретные данные

📝 **Рекомендации:**
- Создайте файл `.env.example` с примерами переменных (без реальных значений)
- Регулярно делайте коммиты с понятными сообщениями
- Используйте ветки для разработки новых функций

## Создание .env.example файлов

Файлы `.env.example` уже созданы в проекте. Они содержат примеры переменных окружения без реальных секретов и могут быть безопасно закоммичены в репозиторий.

**Важно:** После клонирования репозитория скопируйте `.env.example` в `.env` и заполните реальными значениями:
```bash
# Backend
cp backend/.env.example backend/.env
# Отредактируйте backend/.env и укажите реальные значения

# Frontend
cp frontend/.env.example frontend/.env
# Отредактируйте frontend/.env и укажите реальные значения
```
